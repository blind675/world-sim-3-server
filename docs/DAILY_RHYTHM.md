# Daily rhythm and light

Milestone 6 derives light and preferred sleep time from the saved simulation tick. The 360-tick day starts at midnight. Day is 06:00–18:00; night is 18:00–06:00. Ambient light is 1 in the day, 0.55 at night, with one-hour dawn and dusk transitions. Changing `SIM_TICK_MS` changes only real-time playback speed. Changing `SIM_TICKS_PER_DAY` still changes the pinned world configuration and requires a planned migration or reset.

Each initial agent receives a deterministic `diurnal` (80%) or `nocturnal` (20%) preference from the world seed and agent ID, without consuming the simulation random stream. The preference is saved with the agent. Existing snapshots missing it gain the same preference on restore. Diurnal agents prefer to rest at night; nocturnal agents prefer daytime. During that window, tiredness of 0.22 triggers a rest goal. Outside the window, the threshold is at least 0.45, so a missed sleep period still leads to recovery. Hunger and thirst retain priority over rest, and an agent can rest on any walkable cell. Sleeping agents do not scan or update visual memory. Tiredness itself remains nonlethal.

The effective vision radius is the base trait range scaled by ambient light. Nocturnal agents recover 60% of the lost light through night adaptation. At tiredness above 0.5, a further penalty grows to 30% at maximum tiredness; the omnidirectional near-field radius remains available. Milestone 7 also shortens sight during rain; see the [climate model](CLIMATE_MODEL.md). This makes a missed sleep period impair perception before fatal hunger or thirst can occur. The existing field of view, wrapping, terrain/object occlusion, and shoreline discovery rules remain in force. The public agent response includes `traits.circadianType` and `effectiveVisionRange`; simulation status includes `light.phase` and `light.level`. The web viewer uses the effective radius for its vision overlay and dims terrain as light falls.

No new environment variable or snapshot format is required. Snapshot replay and migration tests cover both mid-sleep restoration and an older agent record with no circadian preference. The [milestone 6 baseline](baselines/survival-m6.md) compares survival and walking with milestone 5.
